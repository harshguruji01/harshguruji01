## 👋 About Me

I’m **Harsh Patel**, the founder and builder behind **HarshGuruJi**. I create web and mobile projects around a simple idea: make useful technology, learning resources, and software easier for people to access.

My work brings together educational content, browser-based tools, apps, and community experiences. I enjoy taking a project from an idea to something people can actually use—and improving it along the way.

> **My focus:** accessible learning · practical software · thoughtful technology

## 🚀 What I’m Building

| Project | What it does |
| --- | --- |
| [**HarshGuruJi**](https://webguruji.online) | A digital hub for learning resources, free web tools, software, and more. |
| [**GuruTube**](https://tube.webguruji.online) | An Android video app focused on playback, discovery, and a privacy-minded experience. |
| [**ChatBase**](https://chat.webguruji.online) | A real-time messaging and community platform for web and Android. |
| [**GuruAI**](https://ai.webguruji.online) | An AI assistant experience for exploring ideas, learning, and getting help. |
